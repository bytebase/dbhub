<Tabs>
  <Tab title="npx">
    Try it with a built-in sample database:

    ```bash
    npx -y @bytebase/dbhub@latest \
      --transport http \
      --port 8080 \
      --demo
    ```

    Open the Workbench at [localhost:8080](http://localhost:8080). Requires Node.js 22.5+.

    [Connect your own database →](/quickstart)
  </Tab>
  <Tab title="Docker">
    Run the sample database in a container:

    ```bash
    docker run --rm --init \
      --publish 8080:8080 \
      bytebase/dbhub \
      --transport http \
      --port 8080 --demo
    ```

    Open the Workbench at [localhost:8080](http://localhost:8080). Requires Docker.

    [Docker installation guide →](/installation#docker)
  </Tab>
  <Tab title="Claude Code">
    Run these commands inside Claude Code:

    ```text
    /plugin marketplace add bytebase/dbhub
    /plugin install dbhub@dbhub
    ```

    Enter your database connection string when prompted. Read-only by default. Requires Node.js 22.5+.

    [Claude Code setup guide →](/claude-code-plugin)
  </Tab>
  <Tab title="Codex">
    Set your database connection string:

    ```bash
    export DBHUB_DSN="postgres://user:password@localhost:5432/dbname"
    codex plugin marketplace add bytebase/dbhub
    codex plugin add dbhub@dbhub
    ```

    Launch Codex from this shell. Read-only by default. Requires Node.js 22.5+.

    [Codex setup guide →](/codex-plugin)
  </Tab>
</Tabs>
