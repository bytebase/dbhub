# Sea illustration set

Sixteen reusable illustrations for DBHub documentation and marketing. The mappings below are suggested uses, not changes to the documentation navigation.

## Style

- Canvas: `264 × 176`, transparent background.
- Stroke: `2.2px`, `#323236`, round caps and joins. The original seastar uses its logo path at an equivalent 2.1px stroke.
- Smooth organic curves; no sketch jitter, shading, gradients, or gray accent lines.
- Keep subjects centered with generous space; preserve the canvas when scaling.
- Use at illustration sizes (approximately 176–264px wide), not as 16px navigation icons.
- In dark mode, `filter: invert(1)` matches the existing landing-page treatment.
- For decorative images next to descriptive text, use `alt=""`. For standalone meaningful images, provide an accessible description.
